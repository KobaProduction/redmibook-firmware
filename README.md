# RedmiBook Pro 16 2024 — исследование BIOS и аппаратных интерфейсов

**Целевое устройство:** Xiaomi RedmiBook Pro 16 2024 / плата TM2309, Intel Core Ultra 7 155H (Meteor Lake). Основной исследуемый заводской BIOS — **A0A, 2024-06-04**.

**Конечная цель:** получить достоверную карту полезных аппаратных возможностей для будущего программного управления и мониторинга из **любой поддерживаемой операционной системы** — в первую очередь Windows и Linux. Нас интересуют параметры питания, охлаждения, контроллеров, датчиков, батареи, USB/Thunderbolt, а также возможность изменения частот и напряжений там, где платформа это действительно допускает.

**Сейчас только анализ заводской прошивки.** Приложение, Linux/Windows-адаптеры, сборка собственной BIOS, прошивка ноутбука и испытания — отдельные последующие этапы.

Предыдущие подробные исследования и исходные скрипты из закрытых рабочих веток сохранены в [замороженном архиве](docs/ARTIFACTS.md). Они служат материалом для адресной проверки, а не текущей технической истиной; перенесённые выводы следует проверять в каноническом Analysis.
