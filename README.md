# RedmiBook Firmware

Open-source firmware research and development for RedmiBook laptops.

## Initial target

- Xiaomi Redmi Book Pro 16 2024
- Intel Core Ultra 7 155H

## Current scope

The project is currently focused on documenting the platform firmware, UEFI, ACPI, embedded controller, boot protections, recovery paths, and other board-specific components required to understand what can be safely replaced or opened.

The first target is the Redmi Book Pro 16 2024. Portability to other RedmiBook models will be considered only after the initial platform is understood.

## Status

Research only. There is currently no validated replacement firmware or flashable release.
