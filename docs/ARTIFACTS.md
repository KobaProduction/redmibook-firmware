# Происхождение образа и техническая база

- Платформа: **Xiaomi RedmiBook Pro 16 2024**, плата **TM2309**, Intel Core Ultra 7 155H / Meteor Lake.
- **Основная штатная прошивка для анализа:** линия **A0A**, дата **2024-06-04**. Остальные версии — вспомогательные только для адресного сравнения. Установленный на плате собственный физический дамп отдельно не подменять официальным архивом.
- **Канонический Analysis:** проект `RedmiBook_TM2309_Firmware_Analysis`, стабильный project_id `ghp_2bf17493ef188f564a68d8ae`, сохранённые программы установленных модулей под `/control_modules/installed_2024-06-04/` и `/confirmed_modules/installed_2024-06-04/`. Действительную структуру проекта каждый раз проверять в Analysis, не предполагать, что все модули доступны или уже загружены.
- Исходные firmware/UEFI-модули и капсулы должны храниться как **неизменяемый корпус** с проверяемым происхождением. Этот новый `main` пока **не содержит бинарников и не утверждает их наличие**.
- **Замороженный архив прежних Git-исследований:** подключённое постоянное пространство Files — `projects/redmibook-firmware/legacy-evidence/README.md`, `git-research-534dd9448df0/` (старый README + 13 документов), `git-tm2309-cpu-nvs-8c41ffc0c5b5/` (2 дополненных документа + 6 файлов скриптов). Исходные образы, таблицы ACPI и исследовательские инструменты отдельно сохраняются в `projects/redmibook-firmware/corpus/`, `projects/redmibook-firmware/analysis-scripts/` и `artifacts/redmibook-tm2309/`. Их наличие **не заменяет** доказательства в Analysis. Обновление статусов миграции — в [Issue #2](https://github.com/KobaProduction/redmibook-firmware/issues/2).

Подробные функции, имена/смещения регистров, ABI, трассировки, таблицы и доказательства должны извлекаться из **Analysis**, а не восстанавливаться по этой странице.
