# Карта: температуры, обороты и метрики

**Живой прогресс — [Issue #2](https://github.com/KobaProduction/redmibook-firmware/issues/2), раздел 3.**

Цель: реальные, пригодные для ОС источники CPU/GPU/системных температур, RPM вентиляторов, заряда/разряда, уровня/износа аккумулятора, адаптера и энергопотребления; частоты/нагрузку CPU/GPU предпочтительно получать из штатных API Windows/Linux без ненужного исследования BIOS.

В Analysis имеются OEM H2O-пути отображения пяти показателей охлаждения, EC-чтения батареи и участие ACPI/Intel IPF/DPTF. Протокол H2O и отдельный WMI-пакет не отождествлять без доказательства владельца и порядка полей; заводская заглушка не является реальным датчиком. Не утверждать физическое число вентиляторов по числу ACPI участников.

Карта входных программ Analysis: `H2ODisplayEngineLocalMetroDxe`, `OemODMDxeDriver`, `DptfAcpiPolicy`, соответствующие ACPI/EC объекты и `OemWMISmmCallback`. Точные поля/адреса, промежуточные вычисления и гипотезы смотреть только там.
