# Термины без лишних сокращений

Короткие объяснения для проекта. **Семантические статусы в Analysis и отчётах — только по-русски.**

| Термин | Что означает для ноутбука |
|---|---|
| BIOS / UEFI | Системная прошивка: инициализирует аппаратное обеспечение и передаёт управление ОС. |
| EC (Embedded Controller) | Встроенный контроллер: питание, клавиатура, часть охлаждения и другие периферийные функции. |
| ACPI | Описания и методы для связи ОС с аппаратными функциями: питание, датчики, события и т.д. |
| WMI | Один из интерфейсов команд и событий производителя, особенно видимый в Windows; не единственный возможный канал ОС. |
| SMM / SMI | Защищённый режим обслуживания прошивки / событие его запуска. Наличие обработчика не гарантирует доступное приложение. |
| UEFI Runtime Services | Функции прошивки, которые могут оставаться доступны после запуска ОС, например чтение сохранённых переменных. |
| Setup | Сохранённые настройки платформы. Изменение поля ещё не означает немедленную запись в EC. |
| PL1 / PL2 | Длительный и кратковременный лимит потребляемой процессором мощности. Это **не разгон частоты**. |
| cTDP | Предусмотренный платформой энергетический режим/диапазон CPU. |
| Undervolt | Понижение рабочего напряжения (только если контроллер и защита это позволяют). |
| RPM | Число оборотов вентилятора за минуту. |
| DPTF / Intel IPF | Политики энергопотребления и температуры Intel; могут публиковать возможности без команды изменения аппаратуры. |
| USB PD / Thunderbolt | Питание и расширенные функции USB-C/высокоскоростных портов; доступность управления определяется конкретным контроллером. |
| S5 | Штатно выключенный компьютер, в котором остаются отдельные дежурные цепи. |
| RTC | Часы реального времени, иногда применяются для включения по расписанию. |
| GPIO / MMIO | Контакт управления / регистр устройства, доступный по адресу памяти; физическая разводка не выводится только из адреса. |
| Analysis | Канонический проект исследования, где хранятся технические доказательства, имена функций и структуры. |

**Подтверждено** — есть прямое свидетельство штатной прошивки; **Вероятно** — косвенные согласованные признаки; **Неизвестно** — данных недостаточно; **Противоречие** — имеющиеся данные не согласуются. Статическое подтверждение и физическое испытание — разные уровни.
